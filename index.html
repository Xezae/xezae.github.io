Projects

Automated Solar Panel Cleaning System

Designed and developed an autonomous solar panel cleaning system utilizing a linear actuator, squeegee cleaning mechanism, embedded motor control, power subsystem protection, and fault detection architecture. The system was engineered to improve long-term solar panel efficiency while reducing manual maintenance requirements.

Power Monitoring and Fault Detection System

Developed embedded voltage and current sensing systems using STM32 microcontrollers for real-time subsystem monitoring and fault handling. Integrated ADC measurements, shunt-based current sensing, relay protection, and OLED visualization for power subsystem diagnostics.

Automated Smart Trash Can System (WasteWizard)

Designed and developed an autonomous smart trash can system utilizing ultrasonic sensing, embedded microcontroller control, and real-time actuator response to improve user interaction and waste management functionality. The project integrated distance-based lid activation, sensor feedback processing, OLED display interfacing, and embedded firmware on an STM32 platform.
